# 🏦 Banking Application (Refactored)

## 📌 Description & Motivation
* **Why this project exists:** This banking app was built to simulate essential banking operations with a modern and clean user interface.
* **Problem it solves:** Real banking portals can be overwhelming. This project provides a simple, direct interface for users to create accounts, check balances, deposit, and withdraw funds seamlessly.
* **Who it helps:** Beginners who want an intuitive mock banking platform, and developers looking to understand component-driven architecture, state management, and form validations.

---

## ✨ Features
* 👤 **User Authentication:** Create account, sign in, and active user profile tracking.
* 💳 **Deposit & Withdraw:** Real-time balance calculations with immediate state updates.
* 📊 **All Data / History:** Track transaction activity and view all registered users securely.
* 🛡️ **Validation & Error Handling:** Prevents negative deposits, overdrafts, and invalid characters.
* 🔮 **Upcoming Features:**
  * Two-Factor Authentication (2FA).
  * Transaction history export to PDF/CSV.
  * Dark mode / Light mode toggle.

---

## 🛠️ Technology Stack
* **Frontend:** React.js / HTML5 / CSS3 / Bootstrap
* **State Management:** React Context API
* **Package Manager:** npm
* **Version Control:** Git & GitHub
